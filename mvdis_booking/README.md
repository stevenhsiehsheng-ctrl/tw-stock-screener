# 機車考照預約小幫手（監理服務網）

在**你自己的電腦**上執行。程式會開一個瀏覽器視窗，每隔一段時間到監理服務網「考照預約報名」查一次場次。只要你指定的監理站、日期、組別出現空位，就會：

1. 自動點「報名」，填好身分證字號、生日、姓名、電話、Email，並勾選同意事項
2. **報名頁沒有驗證碼**：直接送出報名，通知你結果
3. **報名頁有驗證碼**：發出聲音、跳桌面通知、寄 Email 叫你。資料已經填好、游標也停在驗證碼欄位，你只要打完驗證碼，程式就會自動送出

> 程式**不會**破解或辨識驗證碼。驗證碼是網站確認「真人操作」的機制，這一步一定要你本人輸入。

> ⚠️ 預約成功但沒到考，會被停止預約 15～60 天。不能去就要在**考照當天 07:00 前**到 <https://www.mvdis.gov.tw/m3-emv-trn/exm/query> 取消。

---

## 事前準備

- **危險感知測驗**：一定要先到監理服務網的危險感知平台完成測驗並登錄紀錄，否則報名會失敗。登錄時的身分證字號、生日，要跟下面設定檔填的一模一樣。
- 一台能上網的電腦（Windows／Mac 都可以），而且等待期間不要關機、不要睡眠。

## 安裝（只要做一次，約 10 分鐘）

1. **安裝 Python**：到 <https://www.python.org/downloads/> 下載安裝。Windows 安裝第一個畫面記得勾選 **Add python.exe to PATH**。
2. **下載這個程式**：在 GitHub 這個儲存庫頁面按綠色 **Code** → **Download ZIP**，解壓縮。
3. **安裝需要的套件**：
   - Windows：打開解壓縮後的 `mvdis_booking` 資料夾，雙擊 **`install_windows.bat`**。
   - Mac：打開「終端機」，`cd` 到解壓縮後的資料夾，執行：
     ```bash
     pip3 install -r mvdis_booking/requirements.txt
     python3 -m playwright install chromium
     ```

## 第一步：偵察模式（強烈建議先跑一次）

監理服務網的網頁結構沒有公開資料，程式是照「畫面上的文字」去找欄位的。第一次請先跑偵察模式，確認程式看得懂網頁：

- Windows：雙擊 **`recon_windows.bat`**
- Mac：`python3 -m mvdis_booking recon`

偵察模式會打開瀏覽器，自動走一遍查詢流程，並點進某個場次的報名頁看欄位。它**不會填你的資料、不會送出**。跑完會告訴你 `summary.txt` 的位置，**請把這個檔案的內容整份貼給 Claude**。裡面沒有你的個人資料，我會依照真實網頁調整程式。

> 還沒寫設定檔也可以跑偵察，只是不會實際查詢場次；寫好監理所、監理站再跑一次會更完整。

## 第二步：寫設定檔

把 `mvdis_booking/config.example.yaml` 複製一份，改名成 **`config.yaml`**（放在同一個資料夾），用記事本打開修改：

- `target`：照類、監理所、監理站、可以考的日期範圍與星期
- `group_include` / `group_exclude`：場次組別。**第一次考照的人要選「初考／需講習」的組別**，不要選「免講習／重考」組。各站寫法不同，程式執行時會把看到的組別都印出來，照著調整即可。
- `applicant`：身分證字號、生日（用西元寫，例如 `2005-07-02`）、姓名、手機、Email
- `notify.email`：要 Email 通知就把 `enabled` 改成 `true`，並填 Gmail 的**應用程式密碼**（16 碼，不是登入密碼；申請網址 <https://myaccount.google.com/apppasswords>，Google 帳號要先開兩步驟驗證）

寫好後可以檢查：

```bash
python -m mvdis_booking check        # 檢查設定檔
python -m mvdis_booking notify-test  # 測試聲音、桌面通知、Email
```

`config.yaml` 有你的個人資料，已經設定成不會被上傳到 GitHub，請不要傳給別人。

## 第三步：開始盯場次

- Windows：雙擊 **`run_windows.bat`**
- Mac：`python3 -m mvdis_booking`

建議先用設定檔預設的 **`mode: dry_run`（測試模式）**：有空位時會幫你填好資料，但不按送出，停在報名頁讓你檢查。確認都填對了，再把 `mode` 改成 **`book`**，之後就會全自動送出。

執行中：

- 黑色視窗會顯示每次查詢的結果；**不要關掉程式開的瀏覽器視窗**。
- 平常大約每 90 秒查一次。每天 08:00 釋出新名額，前後每 20 秒查一次；半夜放慢到 10 分鐘一次。查太快可能被網站封鎖，不建議調快。
- 想停止就在黑色視窗按 `Ctrl + C`。
- 預約成功後，程式會在 `mvdis_booking/state.json` 記下來，之後不會再重複報名。要再約一次的話，先刪掉這個檔案。

## 程式會停下來請你處理的情況

| 狀況 | 程式怎麼做 |
|---|---|
| 報名頁有驗證碼 | 響鈴、通知，等你輸入（預設最多等 3 分鐘）。打完就自動送出；沒等到就繼續盯，下次有空位再叫你 |
| 報名頁有程式認不得的必填欄位 | 能填的先填好，通知你接手。之後可以在 `applicant.extra` 指定，例如 `考照原因: 初考` |
| 網站要求登入會員 | 通知你在那個瀏覽器登入；登入後自動繼續（程式不會記你的密碼） |
| 查不到危險感知紀錄、已經有預約、被停權 | 停下來通知你 |
| 送出後看不出成功或失敗 | 停下來通知你，請到上面的查詢網址確認 |

每次執行的紀錄和截圖都存在 `mvdis_booking/runs/`。出問題時，把 `log.txt` 和截圖給 Claude 看最快。

## 常見問題

- **找不到「板橋監理站」之類的錯誤**：錯誤訊息會列出網頁上可選的名稱，照著改 `station_label` 即可（台／臺都可以）。
- **一直沒有符合的場次**：看黑色視窗印出來的「看到場次組別」，確認 `group_include` 寫的字真的出現在組別說明裡。
- **想用 Edge 不想另外下載瀏覽器**：`browser.channel` 填 `msedge`。
- **電腦要一直開著嗎？** 要。睡眠或關機時程式不會執行。
